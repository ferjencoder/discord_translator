Build command:
pip install --index-url https://download.pytorch.org/whl/cpu torch && pip install -r requirements.txt && python install_argos_models.py

Start command:
python bot.py

Environment:
PYTHON_VERSION=3.12.10
ACTIVE_TRANSLATION_LANGS=en,es,ar,de,fr,no,pt,it
ARGOS_DEVICE_TYPE=cpu
ARGOS_COMPUTE_TYPE=int8
ARGOS_INTER_THREADS=1
ARGOS_INTRA_THREADS=1
ARGOS_BATCH_SIZE=1
ARGOS_BEAM_SIZE=1
ARGOS_CHUNK_TYPE=MINISBD
ARGOS_LOW_MEMORY=true
TRANSLATION_CONCURRENCY=1
TRANSLATION_START_INTERVAL_SECONDS=0.05
TRANSLATION_RETRIES=1
TRANSLATION_TASK_TIMEOUT_SECONDS=90
TRANSLATION_FAILURE_MODE=skip

Keep DISCORD_TOKEN, SERVER_ID, and WEBHOOK_EN/ES/AR/DE/FR/NO/PT/IT.
Keep existing Discord delivery, reaction-channel/category and state settings.
Remove obsolete TRANSLATION_CONNECT_TIMEOUT_SECONDS, TRANSLATION_READ_TIMEOUT_SECONDS,
TRANSLATION_429_COOLDOWN_SECONDS, TRANSLATION_FALLBACK_DELAY_SECONDS and GOOGLE_CLOUD_*.
Inactive language webhooks can be removed. Discord webhook/startup 429 controls still apply.

Build and runtime must use the same ACTIVE_TRANSLATION_LANGS and asset paths.
Defaults store packages and sentence splitters beneath this project at data/argos.
Do not override ARGOS_PACKAGES_DIR or XDG_* between build and start.
The installer downloads exactly the missing required directional models (14 by default)
and preloads sentence splitters. It never deletes unrelated existing models.
Rebuild when changing active languages.

A free Render service may sleep/restart; self-ping is not an uptime guarantee.
RAM and CPU suitability must be measured on Render. No paid plan is required by this code.
Inference runs in a separate process. On timeout/cancellation it is killed and reaped;
the next request starts a fresh worker. Waiting for the slot does not consume its timeout.
The bot can still lose pending messages if Render restarts the entire service.
No new environment variables are required for worker recovery.
